    How this works: this page reads its numbers from a results file that is updated as race calls are confirmed, and it re-checks that file every 60 seconds — no page refresh needed. No results here are projected or estimated — anything not yet called is shown as too early to call. Full automation through a live results feed (Associated Press Elections API or Decision Desk HQ, each requiring an API key) can replace the results file without changing this page's design.
